# 🤖 AI Translation Web Application with IIT-B Corpus

A professional machine learning-based translation web application built using **Streamlit** and Hugging Face's **Transformers** ecosystem.

## 🌟 Key Features
* **Real-time Translation:** Instantly translates English text sentences into Hindi.
* **Dataset Integration:** Embedded with the benchmark **IIT Bombay English-Hindi Parallel Corpus** via Hugging Face API for dataset exploration and validation.
* **Production-Ready UI:** Clean, fully English user interface with interactive sidebar selectors.

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **AI Ecosystem:** Hugging Face (`m2m100_418M` Translation Model & `datasets` library)
* **Data Handling:** Pandas & PyTorch
